# v0.5.0

完善 NX-OS 回显解析和运行态评估，保留 v0.4.0 的类型化 Fabric 与受控变更 API。

- 配置与运行态共享 Parser 文本索引，修复折行、多 VRF 的来源行号，并识别 L2route 零行表格。
- 保留 BGP 汇总精确计数，检查跨段冲突、邻居数量下限和 Port-channel 身份矛盾；补齐 vPC、OSPF、聚合成员和角色接口的只读诊断。
- 更新正式依赖至 net-connector v0.9.0、go-netops v0.4.0、Parser v0.2.2，Go 最低版本保持 1.26.0。
- **配置变更**：清单筛选改用 include_platforms、exclude_platforms、platform_overrides 和 device_rules[].platform；旧键会在连接前拒绝。Go 调用方需更新旧 Connector 导入路径，见[迁移说明](../api-migration.md)。

仅完整且可验证的证据能授权变更；正文为空但缺少零记录依据时仍为 partial。三种自动执行动作、逐项确认及结果不明时不重放、不重连、不自动保存的约束保持。Linux/macOS amd64/arm64；离线回放与合成传输不代替当前实机验收。

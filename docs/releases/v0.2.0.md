# v0.2.0

本版本按网络运维能力重整模块，包含不兼容的 Go 包路径变更；CLI 参数、配置键、JSON schema、精确数值与计划指纹保持原有约定。

- 根包保留证据值；业务拆分为 parser、vendors/nxos、collect、configuration、review、change、report，设备适配位于 adapter/netconnector。
- 公开 cli 包移入 internal/cli；Cobra 命令树、Bootstrap 配置/依赖装配与 Workflow 状态编排各有归属。旧公开入口直接迁移，不提供转发外壳。
- 有序 QuerySpec 统一维度、命令与解析分派；采集显式消费选定 Profile。配置关系、人工建议和可执行计划保持各自的准入边界。
- 使用 Connector 共享清单和配置 API，移除重复字段规则。固定 Connector v0.4.0、Expect v0.4.1，无本地替换。
- 最终通知或输出期间取消/失败时，同步修正返回与磁盘摘要，保留已取得的证据和发布错误，不重新采集或重放命令。

导入路径和构造方式见 [API 迁移](../api-migration.md)。清单缓存须先按新身份刷新；现有快照及变更文件仍按其 schema、指纹和实时前置证据校验。

发行包覆盖 Linux/macOS × amd64/arm64，包含版本/提交身份、许可与 SHA256SUMS。复用同提交 CI 产物并核验附件；离线、模拟会话和 CI 结果不代表真实网络设备验收。

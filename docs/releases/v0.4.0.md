# v0.4.0

引入类型化 Fabric 模型、go-netops 评估/基线/漂移规则和受控变更，属于公共 API 调整。旧 Go 调用者须按 [迁移说明](../api-migration.md) 更新。

- 完整性与健康判断分离，未知事实降为 partial；计数保留精确整数。
- 网关、VLAN/VNI、SVI ACL 变更使用类型化前置条件与回读检查，仍需逐设备逐项确认，不自动重放、回退或保存配置。
- 正式依赖更新为 go-net-connector v0.7.1、go-expect v0.6.0、go-netops v0.3.0。
- 接入 go-standards v1.0.2：共享 lint、架构与 make check。拆分解析、配置加载、证据校验和工作流函数，保留现有语料与黄金结果。

要求 Go 1.26 或以上。Linux/macOS amd64/arm64；模拟设备、冻结语料与独立消费者验证不代替真实网络验收。

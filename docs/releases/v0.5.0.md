# v0.5.0

- 同步更新 pgx v5.13.0、x/term v0.48.0 和 x/text v0.44.0，最低 Go 版本保持 1.26.0。
- 更新正式依赖为 `net-connector v0.9.0`、`go-expect v0.6.0` 与 `go-netops v0.4.0`，构建不使用 workspace 或本地 replace。
- **配置变更**：共享清单筛选改用 `include_platforms`、`exclude_platforms`、`platform_overrides`，设备映射目标改为 `device_rules[].platform`；对应环境变量使用 `NC_*PLATFORMS` / `NC_PLATFORM_OVERRIDES`，旧键会在连接前拒绝。
- 保持 VXLAN 领域 API、设备命令、证据和计划 schema，以及未知结果不重放、不重连、不自动保存的执行约束。

Go 调用方应更新旧 `github.com/gatework/go-net-connector` 导入路径；完整配置迁移见 [API 迁移](../api-migration.md)。本次验证使用合成传输与离线证据，不代表真实设备验收。

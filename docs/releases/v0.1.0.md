# v0.1.0

首个 Go VXLAN 发行版，提供 Cisco NX-OS VXLAN/EVPN 的采集、离线解析、Fabric 审查及受控增量变更。

- 固定 go-net-connector v0.2.0 和 go-expect v0.4.0，最低 Go 1.26.0。
- 已接受并验证的正文与执行错误分别保留，失败回执保留安全元数据，不重放命令。
- OpenSession 回调接收操作 context；接口变更见 docs/api-migration.md。
- 提供 Linux/macOS amd64/arm64 归档、依赖许可证、构建信息和 SHA256SUMS。

发行包复用同一提交通过 CI 的产物，经归档校验和 Linux/macOS 原生冒烟后发布。本版未进行真实设备验收；历史现场记录不是本版实机证明。
